# Thealux

Website fan-made dành cho người chơi **Ngôi Sao Thời Trang VNG** tại Việt Nam.

## Đã có
- Giao diện mobile-first, tối ưu điện thoại.
- Bảng Top 20: Ải hội, Quyển 1, Quyển 2, Khu thi đấu.
- Tìm kiếm item.
- Tủ đồ cá nhân lưu trên thiết bị.
- Dark mode.
- Giao diện đăng nhập demo, sẵn sàng thay bằng backend xác thực thật.
- GitHub Pages tự deploy bằng GitHub Actions.

## Dữ liệu 32.561 item
Thealux được thiết kế để nạp dataset 32.561 item Việt Nam. Bản giao diện hiện tại dùng dữ liệu demo để tránh giả mạo tên/chỉ số/hình ảnh khi chưa có file dữ liệu nguồn được cấp quyền. Con số 32.561 trên giao diện là quy mô dataset mục tiêu, không phải tuyên bố rằng 32.561 bản ghi thật đã được nhập vào repository ở commit này.

Nguồn tham khảo công khai gồm Annie Nikki Homes và Nikki's Info. Annie hiện công bố kho 32.561 trang phục; Nikki's Info có tủ đồ và các mục Ải hội, Khu thi đấu, cùng hướng dẫn theo chặng.

## Bản quyền
Thealux là dự án fan-made độc lập. Tên, hình ảnh và tài nguyên game thuộc chủ sở hữu tương ứng. Không dùng logo/nhận diện của VNG để tạo cảm giác đây là website chính thức.
